# データと外部通信

## 保存先

既定の保存先は次のとおりです。環境変数で変更している場合は、実際の設定先を確認してください。

| 場所 | 内容 |
| --- | --- |
| `runtime/data/` | SQLite、取り込んだメディア、登録語など。旧版の結果やVaultも保持 |
| `runtime/output/` | 文字起こしの書き出し |
| `runtime/models/` | ダウンロードしたモデル |
| `runtime/uploads/` | アップロードの一時ファイル |
| `runtime/logs/` | 起動・実行ログ |
| `runtime/backups/` | バックアップ |
| `config/tokens.json` | APIキー、モデル接続情報など |

録音、文字起こし、話者属性、研究ノート、バックアップは利用者のデータです。アプリのコードと分けて保管・共有してください。`config/tokens.json` は秘密情報を含むローカル設定ファイルです。

## 外部通信

- 初回導入やモデル取得では、Pythonパッケージやモデルの配布元へ接続します。
- 外部AIによる仕上げ等を有効にすると、処理対象の文章や必要な文脈が選択した接続先へ送信されます。OpenAI・Google・TypeSafe等の利用条件や料金は、それぞれの提供元と設定で確認してください。
- LM Studio等を利用する場合も、実際の接続先URLと機能ごとの設定を確認してください。アプリ内で選択したすべての処理が同じ接続先を使用するとは限りません。
- Colab版では録音や処理データをGoogleのランタイムへ取り込みます。Google Drive保存を選んだ場合は、指定したDrive内へ保持します。

既定のWeb待受は `127.0.0.1:7860` です。Colabではノートブックの認証付きポート表示を使用します。

## バックアップと復元

画面からバックアップを作成できます。CLIの場合はアプリを停止してから実行します。

```powershell
.venv\Scripts\python.exe scripts/backup_data.py create
.venv\Scripts\python.exe scripts/backup_data.py verify "<バックアップフォルダー>"
```

通常の対象はライブラリDBと登録語です。旧版の固定分析結果・Obsidian Vault・管理情報・作業台が存在する場合は、それらも互換対象としてバックアップします。元の音声・動画と学習用音声を含める場合は、次を実行します。

```powershell
.venv\Scripts\python.exe scripts/backup_data.py create --include-media
```

`config/tokens.json`、`runtime/output/`、モデル、ログ、一時ファイル、ゴミ箱などは通常バックアップの対象外です。バックアップはデータフォルダー全体のコピーではなく、追加機能の作業データや任意のファイルも自動では含みません。保持したい元メディア・書き出し結果・追加データは別途保管してください。バックアップ作成時には、画面やCLIに表示される除外対象も確認します。

復元は、アプリを停止し、空のデータフォルダーを指定します。

```powershell
.venv\Scripts\python.exe scripts/backup_data.py restore "<バックアップフォルダー>" --data-dir "<空のデータフォルダー>"
```

既定の保存先へ戻す場合は、空の `runtime/data/` を用意して `--data-dir` を省略できます。別のデータフォルダーを使う場合は、起動前に `MOJIOKOSI_DATA_DIR` を復元先へ設定します。復元後の認証情報はセットアップ画面で設定し直してください。秘密情報は通常バックアップと別に保管します。

## コードや結果を共有する

この公開リポジトリには、アプリ・利用手順・実行用定義だけを収録しています。実利用者データ、APIキー、個人の `.codex/`・`.obsidian/` 設定、内部の開発資料を追加しません。公開ブランチのCIでファイルと到達可能な履歴を検査します。

コードを配布するときは、公開リポジトリのZIPまたは `git archive` を使用します。利用中フォルダー全体のZIPには、Git対象外の実データや秘密ファイルも入ります。分析結果・録音・ログ等を共有する場合は、相手へ渡す範囲を確認してください。
